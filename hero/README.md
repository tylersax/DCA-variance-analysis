# Symmetry and Monte Carlo noise in DCA++ — the shareable writeup

One notebook, one data bundle, no dependencies beyond numpy / h5py / matplotlib.

**Read [`symmetrization_variance.ipynb`](symmetrization_variance.ipynb).** It ships executed, with
every figure and table already rendered, so it can be read without running anything.

## What is here

| file | role |
|---|---|
| `symmetrization_variance.ipynb` | **the notebook, and the source of truth.** Edit it directly. Executed output committed. |
| `hero_lib.py` | core: load a run, apply the operator `P`, variances and ratios, orbit structure |
| `reduction.py` | resolving `R` by entry class; the harmonic decomposition; the `rho = 0` ceiling |
| `mechanism.py` | where `rho` comes from; the migration-cloud figure data |
| `summaries.py` | readers for the shipped ensembles — every quoted `R ±` is recomputed here from per-seed records |
| `stage_data.py` | rebuilds `data/` from the original campaign output (needs the machine the runs were made on) |
| `check_executed.py` | verifies the notebook really executed — nbconvert can exit 0 having done nothing |
| `data/` | the shipped bundle, ~45 MB, described by `data/MANIFEST.json` |
| `attic/build_hero.py` | **retired.** Generated the notebook until 2026-07-31; do not run it |

## Editing and re-executing

The notebook is edited directly — prose and cell code both. It used to be generated by
`build_hero.py`, which is now in `attic/` and must not be run: it would overwrite the notebook with
its 2026-07-31 state. None of the computation ever lived there; it lives in the modules above, which
the notebook imports.

After changing any code cell, or any of the modules, re-execute:

```bash
python -m nbconvert --to notebook --execute --inplace \
    --ExecutePreprocessor.timeout=2400 symmetrization_variance.ipynb
python check_executed.py
```

Verify with `check_executed.py` rather than trusting the exit code — nbconvert can exit 0 having
executed nothing. Markdown-only edits need no re-execution.

## What the bundle can and cannot reproduce

| | |
|---|---|
| **Recomputed for all four design points** | orbit structure, orbit sizes, band-equivalence classes, off-block content, symmetry-forced nulls, the geometric ceiling — all properties of the shipped operator `P` |
| **Recomputed from raw per-rank samples** | the validation ladder, per-orbit `r` against the design-effect prediction, the noise mechanism, the migration figure, and a single-run `R` — for square 4×4 and FeAs, whose full runs ship |
| **Recomputed from per-seed records** | every quoted `R ±`: the summaries store one `R` per independent run and the aggregation happens in the notebook |
| **Not reproducible here** | the per-seed `R` values themselves. Those needed the full campaign — about 20 GB of raw run output — which is why they ship precomputed |

Two design points (threeband, square 8×8) ship as operator only: their raw runs are 77 MB and 34 MB,
so structural claims stay live for them while their statistics come from the ensembles.
